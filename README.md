# طلای عقیق — Atelier Intelligence (Demo)

داشبورد ایجنت‌های هوش مصنوعی برای **طلای عقیق یزد** — نسخه دمو (فقط ظاهر، داده‌ها نمایشی است).

## اجرا
```bash
npm install
npm run dev      # توسعه
npm run build    # خروجی استاتیک در dist/
```
- برای رد شدن از انیمیشن ورود: `?open` به آدرس اضافه کنید (مثلاً `/?open#line`).
- ورود: مهر طلایی را **نگه دارید** (یا Enter/Space).
- دستیار سخنگو: روی گوی طلایی بزنید یا `Space`.

## چه چیزهایی دارد
- پس‌زمینه WebGL ابریشم طلای مذاب که نورش دنبال ماوس می‌آید
- شمش و سکه سه‌بعدی (three.js) در اتاق فرمان، استودیوی انگشتر عقیق با چرخش دستی
- گوی طلای مذاب برای دستیار سخنگو + افکت‌های صوتی سنتز شده (WebAudio — بدون فایل صوتی)
- ورود «گاوصندوق»: نگه داشتن مهر، شارژ صوتی، فلش و باز شدن تیغه‌های طلایی
- تعویض پنل نقش‌ها (مدیر کل / حسابداری / انبار / منابع انسانی) با پرده طلایی
- صفحات: اتاق فرمان، ۱۴ ایجنت، خط تولید و مراکز هزینه، فاکتور لحظه‌ای، خزانه (با کد کالا)،
  حسابداری و هزینه‌ها (رایورز)، انبار/تولیدی/مرجوعی/خرابی، پرسنل و غذای اضافه‌کاری، سررسیدها
  (با معادل طلایی لحظه‌ای هر پرداخت) و کارها، استودیو سه‌بعدی، بازار و گزارش روزانه

## برند
رنگ‌ها در `src/styles.css` (`:root`) و لوگو در `src/icons.js` (`LOGO`) — لوگوی فعلی جایگزین موقت است؛
SVG لوگوی رسمی را جایگزین کنید.
